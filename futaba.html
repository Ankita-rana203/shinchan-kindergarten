Fun Facts

Welcome to Futaba!

This website is an unofficial fan tribute to the funny kindergarten from the story of Crayon Shin-chan. I made it as my Web Designing school project, using HTML, CSS and JavaScript.

Facts below are just for fun. You can read more here: Crayon Shin-chan on Wikipedia.
